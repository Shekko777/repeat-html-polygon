## 🛠 Как запустить проект локально

Выполните эти три простых шага, чтобы запустить проект на своем компьютере.

### 1. Клонирование репозитория
Скачайте файлы проекта к себе на компьютер с помощью команды в терминале:
```bash
git clone https://github.com/Shekko777/repeat-html-polygon.git
```

### 2. Установка зависимостей
Перейдите в папку проекта и установите все нужные пакеты:
```bash
npm install
```

### 3. Запуск сервера для разработки
Запустите локальный сервер этой командой:
```bash
npm run dev
```

После этого откройте ссылку из терминала в вашем браузере (обычно это `http://localhost:5173`).
